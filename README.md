# Proyecto Farmacia - Programación IV

## Descripción

Sistema de gestión de farmacia para el curso de Programación IV.

El sistema permitirá administrar medicamentos, categorías, clientes, proveedores y ventas.

## Funcionalidades principales

- Registrar medicamentos.
- Registrar categorías.
- Registrar clientes.
- Registrar proveedores.
- Consultar medicamentos disponibles.
- Administrar inventario.
- Registrar ventas.
- Actualizar el inventario después de cada venta.

## Avance I

En el primer avance se implementarán:

- Clases y objetos.
- Atributos.
- Métodos.
- Constructores.
- Encapsulamiento.
- Getters y setters.
- Herencia.
- Relaciones entre clases.
- Colecciones con ArrayList.
- Objetos funcionando en el sistema.
